# Auction House Web

Aplicación web para consultar y analizar la Auction House.
## Características

- Consulta de subastas por reino.
- Comparación de precios entre múltiples reinos.
- Historial y seguimiento de precios.
- Gestión y seguimiento de oro.
- Búsqueda y filtrado de objetos.
- Interfaz moderna construida con Vue.js.
